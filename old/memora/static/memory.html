添加有证据的关系


















基础模型配置：Embedding 把文本转换为向量；Judge 判断类别、持久性和风险。其他角色与文档处理阶段在“工作流可视化”里按节点配置；总体任务由接入智能体调度。






密钥有两种写法，是两件事：字面密钥由服务端保存、永不回传——已配置时只显示“已配置”，输入框永远从空开始，留空保存表示不改动已存的密钥；环境变量名只是让服务端在调用时从该变量读取密钥。两者同时存在时以字面密钥为准。










本地服务可用 Ollama 的 /v1、LM Studio 或 llama.cpp；云端使用 HTTPS 的 OpenAI 兼容接口。密钥可以填字面值，也可以只填环境变量名——字面密钥在服务端落盘，页面永远拿不回来。保存配置并不代表模型已经连通；“测试连接”会对服务端已保存的 embedding / judge / rerank 各发起一次真实最小调用，如实显示 HTTP 状态、延迟与错误，未保存的草稿不会被探测。
