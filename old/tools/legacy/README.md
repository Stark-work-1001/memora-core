# Historical development scripts

These scripts record the 1.0.0/1.0.1 build and documentation process. They contain historical paths, assumptions and versions and are not supported execution entry points after the source tree was flattened. In particular, they must not recreate the deleted public/release split.

Current entry points: `../build_desktop.py`, `../smoke_desktop.py`, `../release.py`. Current architecture and guides are maintained directly in `../../docs/` and the root README files. Extended components themselves remain in `../../memora/`.
